# مكتبتي الملوّنة — الصف الأول الابتدائي

نسخة تشغيلية من المكتبة التعليمية التفاعلية إلى مستودع **imadtbn/taalam**.

- الموقع: https://imadtbn.github.io/taalam/
- المصدر الأصلي: https://imadmfas.github.io/imadgrade1/
- الواجهات: HTML5 وCSS3 وJavaScript.
- المحتوى: الرياضيات، القراءة، العلوم، التربية الإسلامية، اللغة الإنكليزية، والتربية الأخلاقية.
- دعم RTL، الشاشات الصغيرة، التقدم المحلي، الصوت، ركن الأهل والمعلم، والشهادة.
- لا تسجيل ولا إعلانات.

## الملفات
الصفحة الرئيسية في `index.html` وصفحات الكتب في مجلدات الكتب. كل صفحة تحتوي على محركها وبيانات الدروس المجمّعة. ملفات التشغيل المحلية تشمل `manifest.webmanifest` و`sw.js`.

## ملاحظة مهمة حول الوسائط
نُقلت صفحات التشغيل النصية. ملفات الصوت MP3 (2,490 ملفاً) والخطوط WOFF2 (8 ملفات) ما زالت تُحمّل من استضافة الموقع الأصلي `imadmfas.github.io/imadgrade1`، لأن قناة GitHub المتاحة في جلسة التنفيذ لا تدعم تنزيل/رفع الملفات الثنائية. لذلك هذه النسخة تعمل مع بقاء الموقع الأصلي متاحاً، لكنها ليست مستقلة تماماً عن استضافته للوسائط.

## البنية القابلة للتطوير
المحرك الأصلي يفصل القوالب وCSS وJavaScript وبيانات الكتب في مجلد `engine/` بالمصدر. صفحات النشر هنا هي ملفات HTML مولّدة ومجمّعة. عند تطوير التصميم بصورة منهجية، ينبغي نقل ملفات المحرك المصدرية كاملةً إلى هذا المستودع ثم اعتمادها مصدراً وحيداً لإعادة البناء، بدلاً من تحرير JavaScript المضمّن مباشرة.

## الخصوصية والتشغيل
- يُحفظ التقدم على الجهاز في تخزين المتصفح المحلي.
- إرسال الملاحظات يفتح WhatsApp.
- عداد الزيارات يستخدم خدمة خارجية اختيارية.
- Service Worker يخزن الموارد بعد أول زيارة.
