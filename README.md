# تعلّم — المكتبة التعليمية الجزائرية

مشروع مكتبة تعليمية تفاعلية موجهة إلى **المنهاج الجزائري للسنة الأولى ابتدائي**.

- الموقع: https://imadtbn.github.io/taalam/
- اللغة والواجهة: العربية، مع دعم اتجاه RTL.
- مصدر المحتوى: الكتب والوثائق الأصلية التي يقدّمها صاحب المشروع.
- لا يُنشأ أي نص منهجي أو تمرين أو إجابة بالتخمين.

## الحالة الحالية

بدأ تحويل المشروع من النسخة القديمة المرتبطة بالمنهاج العراقي إلى مشروع جديد للمنهاج الجزائري. أزيلت صفحات الكتب العراقية من نسخة التطوير، مع الاحتفاظ بنسخة احتياطية من المستودع قبل التغيير.

يوجد حالياً ملف PDF واحد في `books/` باسم:

`Arabic Language Textbook for the Preparatory Year.pdf`

لم تُستخرج بياناته بعد. يشير اسم الملف إلى السنة التحضيرية؛ لذلك يجب التحقق من الغلاف والفهرس وتأكيد علاقته بالسنة الأولى ابتدائي قبل بناء كتاب تفاعلي منه.

## بنية المحتوى المعتمدة

```
كتاب
└── وحدات
    └── دروس
        └── أنشطة
            ├── التعليمات
            ├── نوع النشاط
            ├── البيانات
            └── الوسائط
```

كل كتاب مستقل في ملف JSON داخل `content/books/<book-id>/book.json`، ويطابق المخطط في `content/schema/book.schema.json`.

## التحقق والاستيراد

- فحص البنية: `node scripts/validate-content.mjs <path-to-book.json>`
- اختبارات المدقق: `node --test tests/content-validator.test.mjs`
- النموذج التقني المعزول: `prototype/`، ويستخدم بيانات توضيحية لا تمثل المنهاج.

نجاح التحقق البرمجي لا يعني اعتماد المحتوى تربوياً. تتم مطابقة كل وحدة ودرس ونشاط ووسيط مع المصدر الأصلي ثم مراجعتها واعتمادها قبل النشر.

## الخصوصية والتقدم

يُفصل تقدم المتعلم عن بيانات الكتب. لا تُنقل مفاتيح التقدم القديمة إلى كتب المنهاج الجزائري تلقائياً، ولا تُحذف بيانات المتصفح القديمة من طرف المشروع.
