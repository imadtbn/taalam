# الكتب المدرسية الأصلية

توضع هنا ملفات الكتب والوثائق الأصلية كما وردت، دون تعديل.

قبل إنشاء ملف JSON لأي كتاب، يجب التحقق من الغلاف والفهرس والمستوى والطبعة. لا يُستنتج المستوى الدراسي من اسم الملف وحده.

الكتاب المرفق حالياً باسم `Arabic Language Textbook for the Preparatory Year.pdf` محفوظ كما هو، ولم يُعتمد بعد على أنه كتاب السنة الأولى ابتدائي.
