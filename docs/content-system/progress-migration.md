# سياسة تقدم المتعلم عند الانتقال إلى المنهاج الجزائري

## القرار

المحتوى العراقي السابق أزيل من صفحات الموقع في هذا التغيير، لكن بيانات المتصفح المحلية لا تُمسح ولا تُحوّل تلقائياً إلى المنهاج الجزائري.

## التخزين الجديد

يكون لكل كتاب مفتاح مستقل بإصدار واضح، مثلاً:

`taalam:progress:v1:<bookId>`

ويحتوي السجل على إصدار مخطط التقدم، ومعرّف الكتاب، وإصدار المحتوى، والدروس المكتملة، وحالة الأنشطة، وآخر موضع وصل إليه المتعلم.

## قواعد الحماية

1. لا تحذف ملفات المشروع بيانات localStorage الخاصة بالمستخدم.
2. لا تربط تقدماً قديماً بكتاب جديد لمجرد تشابه الاسم أو الترتيب.
3. لا تنشئ ترحيلاً إلا بعد فحص مفاتيح التخزين الفعلية ووضع خريطة ربط معتمدة.
4. تبقى مفاتيح النسخة القديمة خارج نطاق مفاتيح كتب المنهاج الجزائري.
5. يجب أن يكون أي ترحيل مستقبلي قابلاً للتكرار والرجوع، مع نسخة احتياطية قبل التنفيذ.

## النموذج التجريبي

يستخدم النموذج مفتاحاً منفصلاً:

`taalam:prototype:progress:v1:demo-book`

ولا يقرأ أو يكتب مفاتيح الإنتاج.
