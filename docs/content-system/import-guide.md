# دليل استيراد المحتوى

## الملفات المقبولة كبداية
يمكن تقديم المحتوى في PDF أو DOCX أو صور صفحات واضحة أو نصوص أو جداول، مع إرفاق الصوتيات والصور الأصلية إن وجدت. يفضّل تقسيم التسليم حسب الكتاب والوحدة لتسهيل المراجعة.

## بطاقة تعريف كل دفعة
يرفق مع كل دفعة:
- اسم الكتاب/المادة كما يظهر على الغلاف.
- السنة الدراسية والطبعة/الإصدار.
- الصف والمستوى.
- ترتيب الوحدات والدروس كما في المصدر.
- اللغة.
- الملفات الصوتية/الصور المرتبطة وأسماؤها إن وجدت.
- أي تنبيه حول حقوق الاستخدام أو مصدر الملفات.

## مسار التحويل
1. **استلام وأرشفة:** الاحتفاظ بنسخة أصلية دون تعديل.
2. **استخراج:** استخراج النصوص والعناوين والأسئلة والوسائط. تُعلّم الأجزاء غير الواضحة للمراجعة بدلاً من تخمينها.
3. **هيكلة:** تحويل كل كتاب إلى كائن JSON مطابق لـ `content/schema/book.schema.json`.
4. **تدقيق:** تشغيل `node scripts/validate-content.mjs <path-to-book.json>`.
5. **مراجعة المحتوى:** مطابقة ترتيب الصفحات والعناوين والنصوص والتمارين والإجابات مع المصدر الأصلي.
6. **معاينة:** فتح الكتاب في النموذج التجريبي، وفحص الهاتف والحاسوب واللغة واتجاه الكتابة والوسائط.
7. **اعتماد:** لا تُنشر الدفعة قبل موافقة صاحب المشروع.

## قواعد مهمة
- لا تكتب إجابة أو نصاً ناقصاً بالحدس.
- لا تخلط محتوى طبعتين في كتاب واحد.
- احتفظ بمراجع الصفحات أو أرقامها في سجل الاستيراد/المراجعة.
- اجعل أسماء ملفات الوسائط قصيرة وثابتة، واستخدم مسارات نسبية.
- لا تضع بيانات التلميذ أو تقدمه داخل ملفات المحتوى.
- لا تعتبر نجاح المدقق الآلي اعتماداً تربوياً للمحتوى.

## صيغة النشاط
كل نشاط يحمل `id` و`type` و`instructions` و`data`. تفاصيل `data` تختلف حسب النوع، وسيتم تثبيت عقد تفصيلي لكل نوع عند وصول أول عينة فعلية من الكتب، حتى لا نفرض حقولاً لا يحتاجها المحتوى الحقيقي.
