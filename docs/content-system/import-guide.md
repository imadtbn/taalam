# دليل استيراد الكتب الجزائرية

## الملفات المقبولة

PDF أو DOCX أو صور صفحات واضحة أو نصوص وجداول، مع ملفات الوسائط الأصلية (صور/صوت/فيديو) إن وجدت.

## بيانات كل كتاب

قبل تحويل المحتوى، نسجل:
- الاسم كما يظهر على الغلاف.
- المادة والمستوى الدراسي.
- المنهاج والطبعة والسنة.
- الناشر أو الجهة الرسمية.
- اللغة.
- فهرس الوحدات وترتيبها.
- أرقام صفحات الدروس والأنشطة.
- الوسائط المرفقة وارتباط كل وسيط بموضعه.

لا يُعتمد الكتاب على اسم الملف وحده؛ يجب التحقق من الغلاف والفهرس وبيانات الطبعة والمستوى.

## التحويل

1. أرشفة نسخة المصدر دون تعديل في `books/`.
2. مراجعة الغلاف والفهرس وتثبيت بيانات الكتاب.
3. استخراج الوحدات والدروس بالترتيب الأصلي.
4. تقسيم كل درس إلى أنشطة بحسب المصدر.
5. تسجيل تعليمات كل نشاط ونوعه وبياناته ووسائطه.
6. ربط كل جزء برقم الصفحة أو مرجع المصدر.
7. إنشاء ملف `book.json` داخل `content/books/<book-id>/`.
8. تشغيل `node scripts/validate-content.mjs <path-to-book.json>`.
9. معاينة الكتاب ومطابقته مع المصدر.
10. انتظار اعتماد صاحب المشروع قبل نشره.

## قواعد الجودة

- لا تخمين للنصوص أو الإجابات أو أسماء الوحدات.
- لا دمج لطبعات مختلفة في كتاب واحد.
- لا إسقاط للتمارين أو التعليمات أو الوسائط.
- النص غير المقروء يسجل كملاحظة مراجعة مع رقم الصفحة.
- التحقق البرمجي يفحص البنية فقط ولا يثبت الدقة التربوية.
