# نظام المحتوى التعليمي الجزائري

## الهدف والنطاق
إنشاء طبقة محتوى مستقلة عن واجهة الكتب، تمهيداً لاستقبال المحتوى الذي يقدمه صاحب المشروع للمنهج الجزائري – السنة الأولى ابتدائي. هذه المرحلة لا تستبدل أي كتاب حالي ولا تنقل الموقع المنشور إلى المنهج الجديد.

## المبادئ
1. **فصل البيانات عن العرض:** بيانات الكتب بصيغة JSON مستقلة، ومحرك العرض يقرأها ويعرضها.
2. **معرّفات ثابتة:** لا تعتمد هوية الوحدة أو الدرس أو النشاط على العنوان أو ترتيب الظهور.
3. **المحتوى مصدره المالك:** لا يُنشأ محتوى منهجي أو نصوص دروس افتراضية من طرف النظام.
4. **تدرج الإصدارات:** لكل كتاب `contentVersion`، ولكل سجل تقدم إصدار مخطط مستقل.
5. **توافق انتقالي:** تبقى الكتب الحالية كما هي حتى اعتماد المحتوى واختبار التحويل.
6. **RTL أولاً:** اتجاه العرض عربي افتراضياً، مع دعم المحتوى اللاتيني والإنجليزية على مستوى الكتاب/النشاط.

## الكتب الستة
تحافظ طبقة التوافق على المعرّفات الداخلية الحالية لتسهيل الربط لاحقاً:

| المعرّف | اسم العرض المبدئي |
|---|---|
| `reading` | القراءة |
| `math` | الرياضيات |
| `science` | العلوم |
| `islamic` | التربية الإسلامية |
| `english` | اللغة الإنجليزية |
| `ethics` | التربية الأخلاقية |

هذه أسماء تعريفية موروثة من النسخة الحالية وليست توثيقاً نهائياً لتسمية الكتب الرسمية. يمكن تعديل العناوين بعد استلام فهرس الكتب الجزائرية.

## هيكل الملفات المقترح
```
content/
  schema/
    book.schema.json
  books/
    <book-id>/
      book.json
  samples/
    reading-demo.json
scripts/
  validate-content.mjs
prototype/
  index.html
docs/
  content-system/
    architecture.md
    import-guide.md
    progress-migration.md
```

لا يُنقل أي ملف حالي إلى هذا الهيكل في المرحلة الثانية. النموذج التجريبي معزول ويقرأ ملفاً تعليمياً تجريبياً موسوماً بوضوح.

## نموذج البيانات
- الكتاب: هوية المادة، الصف، المنهاج، اللغة، الإصدار، الوحدات.
- الوحدة: معرّف ثابت، عنوان، ترتيب، وصف اختياري، دروس.
- الدرس: معرّف ثابت، عنوان، ترتيب، أهداف اختيارية، أنشطة.
- النشاط: معرّف ثابت، نوع معروف، تعليمات، بيانات النوع، إعدادات اختيارية.
- الوسائط: مسارات نسبية داخل المشروع أو روابط موثوقة مع وصف بديل. لا تُضمّن ملفات MP3/صور ضخمة داخل JSON.
- التقييم: إجابات صحيحة/تغذية راجعة تحفظ في بيانات النشاط، ولا تظهر الإجابة الصحيحة قبل تفاعل المتعلم.

## أنواع الأنشطة الأولية
`text`, `image`, `audio`, `video`, `multiple-choice`, `true-false`, `matching`, `ordering`, `fill-blank`, `drawing`.
يمكن إضافة أنواع جديدة بإصدار محرك متوافق دون تغيير بنية الكتب القديمة.

## سياسة الاستيراد
1. استلام ملفات المحتوى الأصلية من المالك (DOCX/PDF/صور/نصوص/جداول/وسائط).
2. تسجيل مصدر كل مادة وبياناتها: الكتاب، الطبعة، السنة، الصفحة/الوحدة، اللغة، وحقوق الاستخدام عند توفرها.
3. استخراج المحتوى إلى مسودة منظمة، مع عدم تخمين الكلمات غير المقروءة.
4. تحويل المسودة إلى JSON وفق المخطط.
5. تشغيل المدقق الآلي ثم مراجعة بشرية للمطابقة مع المصدر.
6. معاينة الكتاب في النموذج التجريبي على الهاتف والحاسوب.
7. اعتماد دفعة المحتوى قبل نقلها إلى مسار الإنتاج.

المدقق لا يثبت صحة المنهج أو صحة الإجابات؛ هو يفحص سلامة البنية والحقول والمعرّفات فقط.

## قواعد المعرّفات
استخدم معرّفات لاتينية ثابتة بصيغة kebab-case، مثل `unit-01`, `lesson-01`, `activity-01`. لا تستخدم العنوان العربي كمعرّف لأنه قد يتغير. يجب أن تكون المعرّفات فريدة ضمن نطاقها، ولا يعاد استخدامها لمحتوى مختلف.

## حدود المرحلة
- لا تعديل للكتب الستة الحالية.
- لا استبدال للصفحة الرئيسية أو بيانات SEO أو Sitemap.
- لا استيراد فعلي لمحتوى جزائري غير مقدم.
- لا تغيير على Service Worker أو manifest في هذه المرحلة.
- لا اعتماد نهائي لترتيب المواد أو وحداتها قبل وصول فهارس الكتب الرسمية.
